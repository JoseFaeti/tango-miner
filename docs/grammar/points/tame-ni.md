# 〜ために

Status: [~]

## Meaning and tracked scope

purpose or cause; distinguish meanings.

## Verified behavior

- Adjacent attributive predicates or nominal の followed by ために / 為に
  produce a card when a following clause begins. Only ために is reserved;
  the attached predicate or noun remains lexical evidence. Dictionary expression
  precedence can suppress a match. Bare ためになる, demonstrative そのために,
  and sentence-final fragments are excluded.
- Focused tests cover Sudachi split-mode C purpose, benefit and cause examples,
  lexical controls, source examples and reservation. The shared card includes
  both purpose and cause; morphology alone does not distinguish these meanings.
  Semantic disambiguation, demonstrative and other tokenizations remain open.
