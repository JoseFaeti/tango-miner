## Meaning and implementation

Concurrent change: as; in proportion as. This spelling uses the existing
`nitsurete` rule and canonical card identity 〜につれて, avoiding duplicate cards.
See [canonical coverage, tests and limitations](nitsurete.md) for supported
attachments and the literal destination guard. Semantic disambiguation remains
partial.
