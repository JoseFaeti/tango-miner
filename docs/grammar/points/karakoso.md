# 〜からこそ

Status: [~]

## Meaning

Precisely because.

## Verified behavior and limitations

- Matches adjacent causal 接続助詞 から and 係助詞 こそ following a
  sentence-final verb, adjective or auxiliary, including copular forms. The
  card spans からこそ, retaining the preceding predicate as lexical evidence.
  The existing shorter 〜から / 〜ので card also matches the same から;
  dictionary expression precedence can suppress either card.
- Focused tests cover Sudachi split-mode C verb, adjective, copular and polite
  forms, noncausal から, spacing, card identity and token reservation. Other
  tokenizations and corpus-wide precision and recall remain unmeasured. The
  matcher does not verify the semantic relation to a following clause.
