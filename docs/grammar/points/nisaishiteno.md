# 〜に際しての

[Meaning](#meaning) · [Verified coverage](#verified-coverage)

Status: [~]

## Meaning

On the occasion of; in connection with, modifying a following noun.

## Verified coverage

Matches adjacent nouns, pronouns and dictionary-form verbs followed by
に際しての, using the same core token boundaries as に際して. The preceding
word and following noun remain lexical evidence. Focused tests cover Sudachi
tokenization, boundaries, reservation and card identity. The shorter に際して
card also matches. Other tokenizations and inflections are not verified; the
rule does not require a following noun.
