# 〜結果

Status: [~]

## Meaning

As a result of.

## Implemented coverage

Matches 結果 immediately following a past-tense verb or noun + の. Only
結果 is reserved for the grammar card, leaving the preceding action or noun
available as lexical evidence. Focused Sudachi tests cover both attachment
patterns, boundaries, standalone 結果 and card integration.

Noun + の + 結果 can also refer to a concrete result, as in 検査の結果が出た;
the surface pattern cannot distinguish this reading and reserves 結果 there too.
Other tokenizations and uses require further source evidence.
