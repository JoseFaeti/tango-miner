# 〜たりする

Status: [~]

## Meaning

Example or possibility.

## Verified behavior

- Single examples such as 本を読んだりする share the existing
  [〜たり〜たりする](taritarisuru.md) card identity with enumerations.
  This avoids emitting two cards for the same occurrence. The matcher recognizes
  morphology, so it cannot reliably separate an example from a possibility.
- The linked point documents supported predicates, inflections, tests and
  remaining limitations; omitted or separated する remains unsupported.
