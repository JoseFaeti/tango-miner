# 〜げ

Status: [~]

## Meaning

An outward appearance or signs of a feeling or state.

## Verified behavior

- Matches the separate Sudachi 形状詞的 suffix げ after an adjective stem,
  a 形状詞 or 形状詞可能 noun, or あり. Only the suffix is reserved; the
  host remains lexical evidence and following な, に or だ is excluded.
- Focused tests cover observed forms, token boundaries, lexical controls and
  card integration. Sudachi combines 言いたげ as たげ, which is not yet
  matched. Other tokenizations and host forms remain unverified.
