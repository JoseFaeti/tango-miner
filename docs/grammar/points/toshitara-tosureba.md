# 〜としたら / 〜とすれば

Status: [~]

## Meaning

If one supposes.

## Verified coverage

Matches adjacent としたら and とすれば after an expression, including
clauses and adjectives. The preceding expression remains available as lexical
evidence. Tests cover Sudachi tokenization, boundaries, reservation and card
identity.

Attempted actions such as しようとしたら share the same ending and can also
produce this card. Sentence-initial としたら and other tokenizations are not
covered.
