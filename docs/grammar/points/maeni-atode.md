# 〜前に / 〜後で

Status: [~]

## Meaning

Before and after.

## Verified behavior

- Adjacent dictionary-form verbs or nominal の with 前に / まえに and
  past predicates or nominal の with 後で / あとで produce a shared card.
  The match reserves only the temporal phrase and retains attached word evidence.
- Focused tests cover Sudachi split-mode C, both nominal and verb forms,
  lexical controls and card source evidence. The nominal form is ambiguous:
  駅の前に can describe a location rather than time. No semantic distinction
  is attempted. Bare 後で and fused その後で are outside this attached scope;
  other tokenizations and temporal variants remain unverified.
