# 〜とあって

Status: [~]

## Meaning

Because of the circumstances; given that something is the case.

## Verified coverage

Matches an adjacent preceding expression followed by `とあって`, retaining the
preceding expression as lexical evidence. Focused tests cover Sudachi forms,
boundaries, separate `とあっては` and `とあっても` forms, reservation and card
identity. Literal uses of `とあって` can share this tokenization, so a match
does not establish causal meaning. Other tokenizations and written `と有って`
are not covered.
