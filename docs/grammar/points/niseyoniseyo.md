# 〜にせよ〜にせよ

[Meaning](#meaning) · [Verified coverage](#verified-coverage)

Status: [~]

## Meaning

Whether one alternative or another.

## Verified coverage

Matches successive pairs of adjacent にせよ or にしろ markers, including mixed
forms and comma-separated alternatives. The first marker supplies the example
span; the alternatives remain available as lexical evidence. Sentence boundaries
block pairing. The single-marker card can also match the same markers.

Repeated literal imperatives and unrelated clauses can be ambiguous. Complex
contexts, other tokenizations, and corpus precision and recall remain unverified.
Sudachi can analyze に as a copula (for example after 風), which this rule misses.
