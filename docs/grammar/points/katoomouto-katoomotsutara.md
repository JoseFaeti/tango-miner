# 〜かと思うと / 〜かと思ったら

- [Meaning](#meaning)
- [Verified behavior](#verified-behavior)

Status: [~]

## Meaning

Immediately after; no sooner than.

## Verified behavior

- A past verb immediately followed by かと思うと or かと思ったら, including
  hiragana おもう, produces one card. Only the expression is reserved, leaving
  the preceding verb available as lexical evidence.
- Focused tests use Sudachi split mode C and cover both endings, punctuation,
  lexical controls and card reservation. A literal thought or mistaken
  expectation with the same past-verb sequence can also match; the rule does
  not infer the relationship between clauses. Other attachments and tokenizations
  remain unverified.
