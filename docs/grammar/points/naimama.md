# 〜ないまま

Status: [~]

## Meaning

Remaining in a negative state; without doing something.

## Implemented

The rule matches a separate ない negative auxiliary or adjective followed
immediately by a separate まま or 儘 noun, retaining the preceding predicate as
component evidence. It supports verbal, passive, adjective and existential
negative examples verified with Sudachi's full dictionary. The more general
〜まま card can also match the same occurrence. Focused tests cover these
forms, lexical lookalikes, reservation and card identity.

## Limitations

Merged and unusual spellings, other negative forms and corpus-level precision
and recall remain unassessed. A token match cannot establish the intended
interpretation in every context; 〜ぬまま is a separate scheduled point.
