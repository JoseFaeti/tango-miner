# 〜のに

Status: [~]

## Meaning and tracked scope

Concession or purpose; distinguish meanings and nominal uses.

## Verified behavior

- An adjacent attributive verb, adjective or auxiliary followed by Sudachi's
  準体助詞 の and 格助詞 に produces a shared card. This includes noun and
  na-adjective predicates with な, past forms, and sentence-final uses. Only
  のに is reserved; the attached predicate remains lexical. Dictionary
  expression precedence can suppress a match.
- Focused tests cover split-mode C concession, purpose, lexical controls,
  reservation and card examples. The same token analysis also occurs in nominal
  uses such as 赤いのにする; these are currently matched, and meanings are not
  distinguished. Other tokenizations and semantic disambiguation remain open.
