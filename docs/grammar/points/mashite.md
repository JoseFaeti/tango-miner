# 〜まして

Status: [~]

## Meaning

All the more; still less, drawing a stronger inference from a preceding case.

## Verified coverage

Matches the standalone adverb まして, including ましてや, while leaving や
outside the match. Sudachi full dictionary tests distinguish it from the polite
connective in 話しまして, the greeting 初めまして, and the verb in 増して.
Tests cover reservation and the registered identity.

The rule does not verify the preceding comparison or distinguish every context.
Other spellings and tokenizations remain unverified. Dictionary expression
precedence can suppress a match when enabled.
