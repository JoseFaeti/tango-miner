# や / とか

Status: [~]

## Meaning

Non-exhaustive listing.

## Verified coverage

Matches noun-, pronoun-, or numeral-attached `や` and split `と` + `か`
particles, reserving only the listing marker. Sudachi full dictionary tests
cover repeated and single examples, lexical controls, and the contracted
auxiliary in `置いとかなきゃ`. Dictionary-expression precedence applies.
The ambiguous `なんとか` / `何とか` is excluded.

Verb and clause listings, other tokenizations, spaced markers and markers
without an adjacent nominal are unsupported. Some nominal `とか` uses can
express quotation or uncertainty rather than listing; the rule does not
resolve this ambiguity. Corpus precision, recall and lexical effects have not
been measured.
