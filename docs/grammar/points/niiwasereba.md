# 〜に言わせれば

Status: [~]

- [Meaning](#meaning)
- [Coverage](#coverage)

## Meaning

In someone's opinion.

## Coverage

Matches adjacent noun or pronoun + に言わせれば / にいわせれば with
Sudachi's split causative conditional tokens. The source noun remains available
as vocabulary. Tests cover both spellings, boundaries, nearby forms, reservation
and card identity.

The same form can be a literal conditional about making someone speak; those
ambiguous matches remain review candidates. Other spellings and tokenizations
are unverified. The separately scheduled に言わせると is not covered.
