# 〜ともなく / 〜ともなしに

- [Meaning and coverage](#meaning-and-coverage)
- [Limitations](#limitations)

Status: [~]

## Meaning and coverage

Without intending to. The rule matches an adjacent dictionary-form verb followed
by ともなく or ともなしに, reserving only the construction and retaining the
verb. Sudachi full dictionary tests cover both token splits, spacing and controls.

## Limitations

The following clause is not interpreted, so context and meaning can be ambiguous.
Other antecedents and tokenization variants need evidence; 何とはなしに is not
covered by this rule.
