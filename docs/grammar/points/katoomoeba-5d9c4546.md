# 〜かと思えば〜

- [Meaning](#meaning)
- [Verified behavior](#verified-behavior)

Status: [~]

## Meaning

Alternating or contrasting situations.

## Verified behavior

The existing [〜かと思えば](katoomoeba.md) card also matches the expression
following a verb, adjective or noun, including present-tense alternating examples.
Only the expression is reserved. Focused Sudachi split mode C tests cover these
attachments and lexical controls. The matcher does not establish a contrast
between clauses: literal conditional thoughts can also match. Other attachments
and tokenizations remain unverified.
