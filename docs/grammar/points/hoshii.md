# 〜ほしい

Status: [~]

## Meaning

Desire for something.

## Implemented scope

Matches the adjective 欲しい / ほしい in base, past, negative, conditional and
continuative forms supported by the shared adjective helper, with adjacent です.
The adjective remains available for lexical processing. Matches already covered
by the adjacent verb + て / で + ほしい rule are excluded from this card.

Focused tests cover Sudachi tokenizations, inflections, unrelated words, lexical
reservation and card integration. Semantic context is not resolved; other uses
of the adjective may be included. Variants outside the shared helper and action
constructions not recognized by 〜てほしい remain unvalidated.
