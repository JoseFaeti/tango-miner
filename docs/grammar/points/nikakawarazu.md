# 〜にかかわらず

Status: [~]

## Meaning

Regardless of.

## Verified coverage

Matches adjacent にかかわらず, に関わらず and に拘わらず after an
adjacent source token, including noun and かどうか examples. The preceding
token remains lexical evidence. Focused Sudachi tests cover spellings,
boundaries, the neighboring 〜にもかかわらず, reservation and card identity.
The literal negative ずに is excluded. Other analyzer tokenizations and
contextual distinctions between this expression and literal 関わる remain
unverified; the rule does not require a following clause.
