# 〜ないと / 〜なくちゃ / 〜なきゃ

Status: [ ]

## Meaning

Obligation.

This backlog entry concerns standalone elliptical obligations. The related
[complete obligation rule](obligation.md) already supports these forms when
followed by selected complete endings such as `いけない` or `ならない`;
elliptical uses remain unsupported and are the `[ ]` scope tracked here.
