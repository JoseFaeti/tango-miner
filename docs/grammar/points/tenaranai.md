# 〜てならない

Status: [~]

## Meaning

An involuntary, overwhelming feeling; cannot help feeling.

## Verified coverage

Matches adjacent て / で and ならない or 成らない, including past,
なくて, conditional and polite negative forms. The preceding verb, adjective
or adjectival noun remains lexical evidence. Tests cover token boundaries,
reservation and card identity.

The same morphology can describe a literal failure to become something, so
context is needed to distinguish that reading. Literary negatives and unusual
tokenizations remain unverified.
