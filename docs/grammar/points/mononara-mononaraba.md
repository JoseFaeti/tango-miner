# 〜ものなら / 〜ものならば

Status: [~]

## Meaning

If it were possible; also used to challenge someone to do something.

## Tracked scope

The existing [〜ものなら](mononara.md) card covers both `ものなら` and
`ものならば` following an attributive verb. Both forms use the same stable
card identity, `〜ものなら`. Sudachi full-dictionary tests cover potential
and `できる` examples, including a challenge, and incomplete sentences.
Literal nominal readings remain ambiguous, and other tokenizations and
corpus precision and recall have not been evaluated. See the linked point for
the full matcher boundaries, overlap, and limitations.
