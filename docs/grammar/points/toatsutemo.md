# 〜とあっても

Status: [~]

- [Meaning](#meaning)
- [Verified coverage](#verified-coverage)

## Meaning

Even if circumstances are such.

## Verified coverage

Matches an adjacent preceding expression followed by `とあっても`, retaining
the preceding expression as lexical evidence. Tests cover Sudachi forms,
boundaries, related endings, reservation and identity. Literal uses can share
this tokenization, so matching does not establish the concessive meaning.
Other tokenizations and written `と有っても` are not covered; independent
precision and recall remain unverified.
