# 〜や否や

[Meaning](#meaning) · [Verified behavior](#verified-behavior)

Status: [~]

## Meaning

As soon as; immediately after one action occurs.

## Verified behavior

- A dictionary-form verb immediately followed by や否や or やいなや produces
  a card. The marker alone is reserved, retaining the verb. Focused tests cover
  Sudachi split mode C, both spellings, lexical controls and card evidence.
- This surface match does not verify a following action and can mistake a
  question about whether something is so for immediate succession. Other
  tokenizations and inflected or auxiliary forms remain unverified.
