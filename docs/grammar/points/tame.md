# 〜ため

Status: [~]

## Meaning

Reason or purpose.

## Verified behavior

- An adjacent attributive predicate, nominal の, or demonstrative followed by
  ため / 為 and a comma produces a causal card. Only ため / 為 is reserved;
  the preceding source remains lexical evidence. Dictionary expression
  precedence can suppress a match.
- Focused tests cover Sudachi split-mode C, causal forms, lexical controls,
  source examples and reservation. The separate 〜ために rule handles に.
- Unpunctuated causal uses, other continuations and tokenizations remain open;
  the current boundary does not attempt to distinguish purpose semantically.
