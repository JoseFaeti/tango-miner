# 〜と言うまでもない

[Meaning](#meaning) · [Verified behavior and limitations](#verified-behavior-and-limitations)

Status: [~]

## Meaning

Needless to say.

## Verified behavior and limitations

- Matches adjacent と言う / という followed by までもない, までもなかった,
  までもありません or までもありませんでした. The full expression is reserved.
- Focused Sudachi tests cover both spellings, supported endings, spacing and
  unrelated forms. The general 〜までもない rule also matches the same ending.
  Literal quotations can share this morphology; other inflections, dictionary
  precedence and corpus-wide precision and recall remain unverified.
