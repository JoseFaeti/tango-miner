# 〜というより

Status: [~]

## Meaning

Rather than; more accurately, when correcting or refining a description.

## Verified coverage

Matches an adjacent preceding expression followed by `というより`, `と言うより`,
or `っていうより`. The preceding expression remains lexical evidence, and the
shorter という and って rules yield to this construction. Focused tests cover
analyzer forms, boundaries, reservation and card identity. Literal comparisons
involving saying can have the same surface, so a match does not guarantee the
corrective meaning. Contracted forms such as `つうより` and other tokenizations
are not covered.
