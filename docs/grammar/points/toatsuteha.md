## Verified coverage

Matches an adjacent preceding expression followed by `とあっては`, retaining
the preceding expression as lexical evidence. Tests cover Sudachi forms,
boundaries, `とあって` and `とあっても` controls, reservation and identity.
Literal uses can share this tokenization, so matching does not establish the
conditional meaning. Other tokenizations and written `と有っては` are not covered.
