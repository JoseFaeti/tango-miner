# 〜といっては

[Meaning](#meaning) · [Verified coverage](#verified-coverage)

Status: [~]

## Meaning

Whenever saying; repeatedly using something as a reason for an action.

## Verified coverage

Matches adjacent といっては and と言っては, leaving the preceding words as
lexical evidence. Focused tests cover Sudachi forms, reservation, identity and
similar-looking controls. Literal quotations and prohibitions can also match;
the rule does not determine whether the action is habitual or the statement is
an excuse. Other tokenizations and colloquial variants remain unverified.
