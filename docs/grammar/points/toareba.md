# 〜とあれば

Status: [~]

## Meaning

If the circumstances call for it.

## Verified coverage

Matches an adjacent preceding expression followed by `とあれば`, retaining the
preceding expression as lexical evidence. Focused tests cover Sudachi forms,
boundaries, lexical controls, reservation and card identity. Literal uses can
share this tokenization, so a match does not establish the intended meaning.
Other tokenizations and written `と有れば` are not covered.
