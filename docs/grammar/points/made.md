## Meaning

## Verified behavior

Endpoint uses are implemented by the shared [から / まで rule](kara-made.md),
which emits the `から / まで` card. Nominal and verbal endpoints are covered by
focused analyzer tests. The shared rule's
page describes reservation, exclusions, and remaining ambiguity. A separate
card would duplicate the same occurrences; no separate identity is emitted.
