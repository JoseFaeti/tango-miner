# 〜からには

Status: [~]

## Meaning

Now that; since this is the case, a consequence or commitment follows.

## Verified behavior and limitations

- Matches adjacent causal から, に and は following a finite predicate,
  including verb, adjective and copular forms. The card spans からには and
  retains the preceding predicate as lexical evidence. The shorter 〜から /
  〜ので card can also match; dictionary expression precedence can suppress
  either card.
- Focused tests cover Sudachi split-mode C forms, noncausal から, spacing,
  card identity and token reservation. Other tokenizations and corpus-wide
  precision and recall remain unmeasured. The matcher does not verify the
  semantic relationship to the following clause.
